# DE and Pathway Analysis – HNSCC

This project analyzes gene expression data from head and neck squamous cell carcinoma (HNSCC) to identify genes that are differentially expressed between tumor and normal tissue and explore the biological pathways associated with those changes.

## Analysis

* **Differential expression analysis:** Identifies genes with significant expression differences between groups
* **Pathway analysis:** Explores biological processes and pathways associated with differentially expressed genes
* **Data visualization:** Uses plots to summarize gene expression and pathway-level results

The analysis uses R to process gene expression data, identify differentially expressed genes, and investigate the biological pathways represented by those genes.

The goal is to better understand the molecular changes associated with HNSCC and identify biological processes that may be relevant to the disease.

## Tools

* R / RStudio
* `DESeq2`
* `ggplot2`
* `dplyr`
* Pathway enrichment analysis
